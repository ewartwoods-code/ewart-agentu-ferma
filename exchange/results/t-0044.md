## What I built

A routing framework whose whole job is to answer one question — *which provider
and which model should serve this agent for this task* — and to answer it as a
**recommendation**, not an action. It spends nothing and calls nothing.

### The distinction the whole design turns on

`anthropic/claude-opus-5` reached **through OpenRouter** and **dedicated Claude**
are not the same capability, even where the weights are identical:

- Through OpenRouter: one chat completion. No file tools, no Bash, no MCP, no
  repo access, no agentic loop. Text in, text out.
- Dedicated Claude: Claude Code on this Mac — repo mounted, tools on, MCP
  connectors reachable, many turns.

Anything needing the second cannot be served by the first at any price. So
`claude_special` is a **hard override** in front of the cost/quality scoring, not
an input to it. The detection is intentionally over-inclusive, because the two
failure directions are not symmetric: mis-routing a simple task *to* Claude
wastes some subscription tokens, while mis-routing a tool-needing task to a bare
completion endpoint produces confident garbage that nothing downstream can
detect. The router always reports which rule fired.

### Reusing the existing roster

The agent ids are the farm's real roster (`milk`, `eggs`, `chop`, `plant`, `mow`,
`pigs`, `dig`, `herme`), taken verbatim from `scripts/sync-tasks-to-db.js`'s
`AGENT_ROLES` rather than invented fresh — so this repo has one roster, not two
that drift apart.

**How "no HTTP call" is actually proven**, rather than asserted:

1. `globalThis.fetch` is replaced for the whole suite with a counter that also
   throws. The run ends by printing that counter and failing if it is non-zero.
2. The client is separately called with an **injected** counting `fetchImpl`;
   the dry-run path is asserted to leave it at `0`.
3. A real (non-dry-run) call with no key is asserted to **throw `NO_API_KEY`**
   rather than fire an unauthenticated request — also verified at `0` calls.
4. The client source is scanned for anything shaped like a key.

## Honest limits

- **No non-Claude model executed anything.** There is no key, so no such call was
  possible. Every non-Claude route reports `status: "configured-not-live"`, in
  the router's own output, so a caller cannot mistake a plan for a capability.
- **Nothing calls the router in production yet.** `scripts/autopilot.sh` still
  invokes `claude -p` unconditionally. Wiring is a separate change.
- **Two catalog gaps, stated rather than papered over.** `meta-llama/*` and
  `mistral*/` were not reached before the catalog response truncated, so they are
  *unverified*, not known-absent, and were left out of the registry.
  `google/gemini-2.5-flash` — the model `knowledge/agents-inventory.md` records
  for the SEO agent — did not appear in the catalog and is probably stale.
- **The per-agent mapping is a proposal.** Hermes and the owner should read
  `docs/providers.md` §3 and disagree with it where they disagree; the mapping is
  one table in one file precisely so that is cheap.
