## What I did

The vision's two levels were built as two separate surfaces, and the split is enforced:
**nothing farm-wide appears inside a minion profile, and the boss panel is the only
place aggregate numbers exist.**

All work is in one file: `app/src/public/index.html` (917 -> 1374 lines).
No other file was touched. No migration was needed — every table the vision names
already exists and already has a public read policy.

### 1. Per-minion "their work" — `index.html:624-692` (markup), `961-1123` (logic)

The old modal was a flat page with a "Pilns pārskats" toggle that lazily loaded 25
events. It is now a personal page with three tabs:

| Tab | Content | Source |
|---|---|---|
| 🧰 Viņa darbs | current activity, 5 status counters, its own task list split ATVĒRTIE / PABEIGTIE, each with result summary, reject note and only the timestamps that exist | `tasks?agent_id=eq.<id>&order=created_at.desc&limit=50` |
| 🪪 Profils | who it is (role + joined date + id), skill chips, its own numbers | `agents`, `agent_skills`+`skills`, `agent_usage` |
| 🕓 Vēsture | its own event timeline | `agent_events?agent_id=eq.<id>&limit=25` |

Above the tabs: the status pill, an identity badge row, and the agent's own quote.
The five fetches run in one `Promise.all` (`index.html:1013-1021`).

`openModal()` was rewritten (`index.html:969-1123`). One correctness detail worth
naming: a guard at `index.html:1032` drops a slow response if the visitor has opened
a different agent meanwhile, so a late fetch can never paint agent A's tasks into
agent B's profile.

### 2. Per-minion personalization — `index.html:951-958`, `1035-1051`

Each minion feels like itself, from its own rows:

- **Its own voice** — `agent_status.quote` rendered as a pull-quote
  (`index.html:1037-1040`). If the quote is empty the line is *hidden*, not filled
  with a placeholder.
- **Its own colour** — `agentAccent(id)` (`index.html:951-957`) hashes the agent id
  into a stable hue that drives the video ring, the active tab underline, the quote
  bar and the tier badge. Presentation only; no data is derived from it.
- **Its own badges** — tier, the approval gate, its own task count, its own last
  activity date (`index.html:1042-1050`).
- **Its own metric set** — `index.html:1091-1120` builds the number row from what
  that agent actually has: token tiles only if `agent_usage.last_synced_at` is set,
  a "gaida OK" tile only if it has review tasks, an "atgriezti" tile only if it has
  rejected ones, and an average-duration tile only if it has a task with both
  `started_at` and `completed_at`. Two different minions genuinely get two different
  number rows.

**Honesty rules applied here:** an agent with no usage row shows
"Tokeni vēl nav sinhronizēti", never `0`. A `cost_usd` of `0` renders as
"— izmaksas netiek uzskaitītas" rather than a confident `$0.00`
(`index.html:1101-1103`) — that 0 is written unconditionally by `/api/usage/sync`
(`app/src/server.js:264`) and is not a measurement.

On the permission badge: `agents` has no permission column, so a per-agent
`read`/`write` badge would have been invented. The badge shown
(`✋ Darbu apstiprina saimnieks`) states the real, schema-level invariant — every
write goes through a token-gated `admin_*` RPC — and a proper per-agent field is
listed in `next_steps`.

### 3. Herme aggregation panel — `index.html:694-734` (markup), `1131-1271` (logic)

A new button in Herme's click menu (`📊 Visas fermas kopskats`, `index.html:688`)
opens the boss surface. Six sections, all farm-wide:

1. **Uzdevumi pēc statusa** — counts across all agents, plus an honest note: either
   "Kopā N uzdevumi visā fermā" or, if the 500-row window is hit, "Rādīti pēdējie
   500 — kopskaits var būt lielāks" (`index.html:1179-1182`).
2. **Gaida saimnieka apstiprinājumu** — the approval queue, each row with an inline
   ✔ Pieņemt button calling the existing token-gated `admin_approve_task` RPC.
3. **Minjoni** — one line per minion (boss excluded), with its live task, its own
   active/review/done counts and its tokens. Clicking a line opens *that* minion's
   personal profile (`index.html:1223-1235`) — this is what makes every agent
   reachable, since the field itself only shows minions that have a live task.
4. **Tokeni un izmaksas — visa ferma** — summed only over agents that are actually
   synced, with `N/M aģenti sinhronizēti` and the last sync time, and the same
   no-fake-cost rule.
5. **Pēdējie notikumi fermā** — last 12 events across all agents, each named.
6. **Fermas plāns** — `farm_plan.content`, or a pointer to the control panel if empty.

Approving from inside the panel refreshes both the field and the panel
(`index.html:875-877`).

### Security invariants

- **No schema change, no new policy, no new RPC.** Nothing was added to
  `app/supabase/`, so the "public read, no public write" invariant and the
  policy-free `app_secrets` are untouched by definition.
- **The page reads only.** The request audit above shows 48 REST calls across 7
  tables, all with the anon key. The only write the page can still perform is the
  pre-existing `admin_approve_task` RPC, which is token-gated server-side and
  prompts for the token via `sessionStorage`; the new inline approve button reuses
  that exact path (`approveTask()`), it does not add a second one.
- **No key reaches the client.** The served HTML contains no service-role key, no
  Anthropic key and no admin token (checked above), and both placeholders are
  substituted to zero occurrences.

## Notes for Hermes

1. **This did not deploy anything.** `app/src/` in this repo is a snapshot; the live
   site builds from `ewartwoods-code/ewart-agentu-ferma` `main` on Railway. Shipping
   this to visitors is an outward-facing change and needs the owner's OK.

2. **Language decision, made deliberately.** The quality skill says "no Latvian
   diacritics in files", but `index.html` is a Latvian user-facing page whose
   existing strings all carry diacritics. Mixing "Vesture" next to "Vēsture" would
   look broken. So: **UI strings keep proper Latvian (matching the file), every
   comment and identifier is English**, and the file is verified as clean UTF-8 with
   zero replacement characters. If Hermes wants the stricter reading, say so and the
   whole page can be transliterated in one pass.

3. **`app/src/index.html` (the dead 614-line copy) is still dead and I left it
   alone.** `resolveTemplate()` checks `public/` first, so it is unreachable. Anyone
   who opens that file looking for this feature will not find it. It should be
   deleted in its own task rather than silently here.

4. **The cost number is still not real on the server side.** I fixed the UI so a
   zero never renders as `$0.00`, but `fetchAnthropicUsageFor()` still returns
   `costUsd: 0` unconditionally. Finishing it properly requires a paid
   `ANTHROPIC_ADMIN_API_KEY`, which is a `needs_review` decision for the owner.

5. **Verified against fixtures, not against production.** The fixture rows were
   shaped from the documented schema (`ferma-supabase-backend.md` and the four
   migrations). I had no Supabase credentials in this run, so I could not read the
   real policy list back and did not claim that check as passed.

6. **The field's behaviour is unchanged** — minions still only walk out when they
   have an active/review task. The aggregation panel's minion list is now the way to
   reach a resting agent's profile, which previously was not clickable at all.
