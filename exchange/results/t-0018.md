## What I did

### 1. Migration — `app/supabase/migrations/20260816170000_subscriptions.sql`

A draft of this file already existed (commit `4c5335c`, written by Hermes after the task was
issued). I rewrote it, because as drafted it broke two rules of this repo:

| Problem in the draft | Why it mattered | Now |
|---|---|---|
| Latvian **diacritics** in seed strings (`Kodērijš`, `Attēlu/video ģenerēšana`, `zīm/mēn`) | `ferma-supabase-backend.md` §5: no Latvian diacritics in a `.sql` file — they have corrupted files here before | ASCII-only Latvian, the same convention the existing RPC bodies use (`Stradaa...`) |
| `Higgsfield ... 9.99, 'USD'` with the note "no t-0002: plus plāns" | t-0002 measured only `subscription_plan_type: "plus"`, **never a price** — so 9.99 was an invented number, which the task forbids twice | `null` cost, plan `Plus` kept, provenance cited in the note |
| No unique key, `on conflict do nothing` with nothing to conflict on | the clause was inert; a re-run would have duplicated all 7 rows | `subscriptions_name_key` unique index + `on conflict (name) do nothing` |
| `cost_currency` set on rows with no amount | a currency without an amount is not information | `null` currency alongside the `null` amount |

The table is exactly the column list from the task. RLS on, **one** policy
(`for select using (true)`), no insert/update/delete policy, `app_secrets` untouched — the
no-public-write invariant holds. Header records that it was NOT applied to the live database.

- **Styles** (`app/src/public/index.html:311-365`, mobile at `:761-765`): reuses the existing card

  colours reuse `--work` / `--accent` exactly like the field dots.
- **Logic** (`app/src/public/index.html:2063-2196`): `costNumber` / `fmtMoney` / `subsTotals` /
  `subRowHtml` / `renderSubscriptions`.
- **Fetch** (`app/src/public/index.html:2215`, rendered at `:2227`):
  `sbGetOptional('subscriptions?select=*&order=owner_sort.asc')`
  — the same tolerant path `token_budgets` uses, so an unapplied migration degrades only this
  block and never the farm.

Four honesty decisions, all enforced by tests:

1. **Blank is not zero.** `Number(null)` is `0`, which would have made an unpriced service look
   free and quietly join the totals. `costNumber()` returns `null` for `null` / `''` / garbage and
   `0` only for a real `0`.
2. **Currencies are never summed.** The page holds no exchange rate, so EUR and USD get their own
   tiles and the note says why. A yearly cost is converted to a monthly share (`/12`) and back — that
   is arithmetic on one currency, not a made-up rate.
3. **Only `active` rows count.** A cancelled service is not money going out. The note states it, and
   a paused/cancelled row is labelled in *words* (`Pauzēta` / `Atcelta`), not by dot colour alone.
4. **The empty states are distinct.** `Subskripciju vēl nav.` (register empty) vs
   `Tabula "subscriptions" vēl nav datubāzē` (migration not applied). Collapsing them would tell the
   owner he has no subscriptions when the truth is the table is missing.
