## What I did

### 1. `app/src/public/index.html` — the profile modal

- **Markup (lines 1152-1170).** The profile tab now holds `Skilli` (unchanged),
  `Padarītie darbi` (`#mDoneWorks`), `Moduļi` (`#mModules`) and
  `Izmaksas un tokeni` (`#mCost` + the existing token meter `#mMeter`). The
  meter moved under the new cost heading instead of being duplicated.
- **New rendering helpers (lines 2201-2395)**, all pure and unit-tested:
  - `artifactRefsFrom()` — pulls file refs (`artifacts/…`, `exchange/results/…`)
    out of a task's own `result_summary` / `description`, de-duplicated, max 6.
    Tasks carry no artifact column, so the text is the only honest source.
  - `isSafeHref()` — a `result_url` becomes a live link only for `http(s)` or a
    same-origin `/path`; `javascript:`, `//host` and anything containing a quote
    or angle bracket is refused (the page's `escapeHtml()` does not escape `"`,
    so a quote in an `href=""` would be an attribute-injection hole).
  - `doneWorksHtml()` — finished works only, newest `completed_at` first, each
    with its module tag, summary (or "kopsavilkums nav ierakstīts"), artifact
    chips and the optional result link.
  - `modulesForAgent()` — one entry per (provider, model). `runs` comes from
    `agent_module_usage`, `works` from `tasks.model_used`; they are kept apart
    so the same work is never counted twice. Tokens and cost stay `null` when no
    row measured them.
  - `modulesHtml()`, `moneySumsFrom()`, `costAndTokensHtml()` — money is summed
    per stored currency and never converted; the existing `costNumber()` /
    `fmtMoney()` from the subscriptions block are reused rather than
    re-implemented, so the two surfaces can never disagree.
- **Wiring (lines 2749-2850).** `openModal()` additionally fetches
  `agent_module_usage` through `sbGetOptional()` (tolerant: a table that does
  not exist yet degrades one section, not the page), renders the three new
  blocks, and the old "Viņa skaitļi" row lost its token and cost tiles — those
  now live once, in the cost block.
- **CSS (lines 747-763)** — `.mod-chip`, `.art-chip`, `.wi-artifacts`.

### 2. `app/supabase/migrations/20260817160000_agent_modules_and_cost.sql` — CREATED, NOT APPLIED

Truly needed: nothing in the database records which model did which work.
`tasks` has no model column and `agent_usage` is one row per agent with token
counts only (`/api/usage/sync` answers `cost_tracked: false` and never writes a
cost). The migration adds:

- `tasks.model_used`, `tasks.provider`, `tasks.result_url`;
- `agent_module_usage(agent_id, provider, model, runs, input_tokens,
  output_tokens, cost_amount NULL-able, cost_currency, last_used_at)`, RLS on
  with a **read-only** policy — no public write policy, same invariant as every
  other table.

`cost_amount` is nullable on purpose: NULL means "not measured" and renders as
"izmaksas netiek mērītas". A 0 there would read like a measurement.

## Notes for Hermes

1. **Nothing measures a module today.** Until 20260817160000 is applied AND a
   writer stamps the rows, every profile will read "moduļi netiek reģistrēti".
   That is the honest state, not a bug — I did not derive the module from the
   parent platform, because the platform an agent hangs under is not evidence of
   which model a given work used.
2. **The writer is a separate task.** `scripts/model-runner.js` already knows the
   provider, the model and the OpenRouter `usage` block at the moment it writes a
   result; `scripts/sync-tasks-to-db.js` already pushes tasks into the DB. Wiring
   either to persist `model_used` / `agent_module_usage` is a live-data write, so
   it is outside `code_local`.
3. **Currency.** The task asked for €. Recorded amounts are stored per row with
   their own currency (OpenRouter bills in USD) and this app holds no exchange
   rate, so the UI prints the stored currency and says so. Re-labelling a USD
   amount as EUR would be an invented number.
4. **Headings.** The task wrote "Skili"; the existing section is already
   "Skilli", which is the correct Latvian, so it was left as it is. The other
   three headings are verbatim: "Padarītie darbi", "Moduļi",
   "Izmaksas un tokeni".
5. **Nothing was removed except duplication:** the token/cost tiles that used to
   sit in "Viņa skaitļi" now exist once, in "Izmaksas un tokeni". No dead file,
   no commented-out block, no placeholder rendering as data.
