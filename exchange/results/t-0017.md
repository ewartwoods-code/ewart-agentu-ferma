## What I did

### 1. Wrote the Intelligence Agent contract — `docs/intel-agent.md`

The durable deliverable. It defines:

- **The one hard rule:** a claim without a source is a *hypothesis*, not a finding. A URL may
  never be attached to a claim unless that exact URL was fetched in this run and contained it.
  A plausible fake citation is worse than none — nothing downstream can detect it.
- **A capability gate.** The agent checks it has a read route (WebSearch / WebFetch / curl /
  paid Grok) *before* starting. With no route it must produce a research **plan**, not findings.
- **A 5-tier source hierarchy** — official/primary → platform-adjacent → reputable industry →
  community/forums/X → model prior knowledge (which is *never* a source, only a hypothesis).
  Official and community claims stay visually separated in every note.
- **The 1-10 rating scale**, with the rule that every rating must be followed by
  *"would rise to N if <concrete check>"*. A rating with no path upward is a lazy rating.
- **The owner gate**, as an explicit two-shelf model:
  `knowledge/research/` = draft shelf, agents must not consume it;
  `knowledge/now/` = approved shelf, owner sign-off required to enter.
- **A refresh policy**: 90 days general, 60 days for ad-platform notes.

It is written *as* a Claude skill (frontmatter included) but had to land in `docs/` — the write
to `.claude/skills/` was permission-denied on this node. Moving it is a one-line action, listed
in `next_steps`.

### 2. Note template — `knowledge/research/_TEMPLATE.md`

The 9-section format: topic/question, status banner, overall rating, per-finding rating + source,
source table with tiers and dates, contradictions table, freshness, consumer agent, and
"what would change this note".

### 3. Two shelves — `knowledge/now/README.md`

Documents the gate from the consuming agent's side: check the rating, check the re-check date,
and never silently resolve a contradiction the note left open. Currently empty by design.

### 4. Demo note — `knowledge/research/etsy-listing-best-practices-2026.md`

**This is where the honest part matters.** The task asked for a real sourced note on Etsy listing
practices. I could not produce one, because there was no way to read anything:

| Route | Attempted | Result |
|---|---|---|
| `WebSearch` ("Etsy search ranking factors 2026") | yes | permission not granted — refused |
| `WebFetch` (etsy.com Seller Handbook article) | yes | permission not granted — refused |
| `curl https://www.etsy.com/seller-handbook` | yes | permission not granted — refused |
| OpenRouter / `x-ai/grok-4.6` (X + web) | no | no `OPENROUTER_API_KEY`; a live call costs money, which this task's own constraints forbid |

I had two options and deliberately took the second:

- **(A)** Write confident-sounding Etsy advice from model memory and attach plausible Etsy URLs.
  This would look exactly like a finished research note and would be **fabricated sourcing** —
  the single failure mode this agent exists to prevent.
- **(B)** Stage the note as `DRAFT-UNVERIFIED` at **3/10**, state plainly that zero sources were
  fetched, and convert the model's prior knowledge into **8 numbered hypotheses (H1-H8)**, each
  rated 3-4/10, each naming the official page that would confirm or kill it.

The note therefore has real value as a **verification checklist**, not as truth. Specific care taken:

- Only **root URLs** are listed as source targets (`etsy.com/seller-handbook`, `help.etsy.com`,
  `community.etsy.com`, `reddit.com/r/EtsySellers`, `erank.com/blog`). Deep-link article IDs from
  memory were deliberately **not** written down — a guessed deep link is a fabricated citation.
- **H7 (fees / Offsite Ads)** carries an explicit instruction: *do not price anything off these
  numbers*. Fees change often and this is the most dangerous item to trust.
- **H2** flags that the "free shipping over $35" placement advantage was historically **US-only** —
  close to irrelevant for our EU markets, and a thing community advice routinely gets wrong for us.
- The **contradictions table is empty and says why**: contradictions need two sources, and zero
  were read. It names the three disputes the real run should expect (renew-boost folklore, tag-title
  matching, free-shipping thresholds outside the US).
- The note cross-references `knowledge/owner-strategy/etsy-ads-search-terms.md` (t-0035) and notes
  that **our own measured ads data is more trustworthy than any hypothesis here**.

verified, while the demo note's *content* is blocked. `needs_review` is used because both open items
are owner decisions, which is the routing you need.
